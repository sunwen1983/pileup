# PileUp — submission draft

## Project description (for the submission form)

PileUp turns a messy pile of life admin into a plan. Dump in whatever
landed on you — a school flyer photo, a utility bill PDF, a voice memo,
a chat screenshot, a handwritten note — and three Muse Ember agents do
the work: one classifies each item, one pulls out the dates, amounts and
actions, and one orders everything by date, flags conflicts, and acts
on it. The plan isn't just a list: PileUp creates the calendar events
and reminders through real MCP tools, served by mcpgate.

Every agent call is visible in a live trace with its tokens and cost,
and a running cost meter shows the whole pile's spend. The five-item
demo pile costs under five cents — Ember's ten cents per million input
tokens and fifty cents per million output make the messy pile a rounding
error. PileUp was built entirely during the hackathon window.
